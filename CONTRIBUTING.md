# Contribuindo com o Sun Website

1. Crie uma branch para sua alteração.
2. Rode `npm install`.
3. Use `npm run dev` durante o desenvolvimento.
4. Antes do commit, rode `npm run check` e `npm run build`.
5. Preserve o design system em `design-system/sun/MASTER.md`.
6. Não altere a sintaxe documentada sem conferir o compilador `sun.lua`.

Mudanças de UI devem manter acessibilidade, navegação por teclado, responsividade e contraste.
